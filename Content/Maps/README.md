# SeededArena (P3-T25)

Create `SeededArena.umap` in the Unreal Editor under this folder, place one `ASeededPropSpawner` actor (defaults: seed 7, 200 props), and set **Project Settings → Maps & Modes → Editor Startup Map / Game Default Map** to `/Game/Maps/SeededArena`.

`*.umap` assets are stored with Git LFS per `.gitattributes`.
